# Pascal → Блок-схема

Десктопное приложение для построения блок-схем по исходному коду на языке Pascal.

Написал программу — получил готовую блок-схему. Подходит для учебных задач и курсовых работ.

## Возможности

- Разбор кода Pascal (свой лексер и парсер)
- Автоматическое построение блок-схемы
- Вход и регистрация через Supabase (PostgreSQL)
- Учебные группы, задания преподавателя, сдача работ, оценки
- Работает офлайн (без входа) и онлайн (с аккаунтом)

## Запуск

```bash
npm install
npm start
```

## Сборка установщика (Windows)

```bash
npm run dist:win32   # 32-bit
npm run dist:win64   # 64-bit
```

## Технологии

- Electron
- Supabase (PostgreSQL, Auth, Row Level Security)
- CodeMirror (подсветка Pascal)
